### 🧠 Core Philosophy: Pragmatic Problem Solving

Whether troubleshooting a blown capacitor on a motherboard, isolating data leakage in an ML pipeline, or diagnosing an SLA drop in postal delivery routes, I apply **first-principles thinking and rigorous root-cause analysis (RCA)**:
- **Dissect Complexity:** Break nebulous business friction into testable hypotheses, robust data contracts, and quantifiable metrics.
- **Iterative Troubleshooting:** Trace failure points methodically—from hardware signals and software logs to outlier distributions.
- **Actionable Remediation:** Deliver robust, repeatable solutions rather than cosmetic quick fixes.
